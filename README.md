# HaseDB – Handy-Version

Smoke-Counter, neue Einträge und Reviews für das iPhone.
Die Daten liegen in Supabase (dieselbe Datenbank wie die Mac-App HaseDB).

- `index.html` – Aufbau der Seiten
- `style.css` – Design (Neo-Brutalismus, gleiche Farben wie die Mac-App)
- `app.js` – Logik (Login, Smoke-Counter, Liste, neuer Eintrag)
- `config.js` – Supabase-URL und öffentlicher Schlüssel

Aufs iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
